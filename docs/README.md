# Documentación del proyecto

Esta carpeta reúne la memoria técnica y metodológica de **Diagnóstico de startups · Panel de expertos**. El objetivo es que las decisiones puedan revisarse sin reconstruirlas a partir de conversaciones o commits aislados.

| Documento | Para qué sirve |
|---|---|
| [Historia y decisiones](HISTORIA-Y-DECISIONES.md) | Explica qué se cambió en cada etapa, qué problema resolvía y por qué se tomó cada decisión. |
| [Metodología y datos](METODOLOGIA-Y-DATOS.md) | Define el instrumento actual, las unidades de análisis, las tablas, los indicadores y sus límites de interpretación. |
| [Arquitectura y operación](ARQUITECTURA-Y-OPERACION.md) | Describe el flujo navegador–Vercel–Google Sheets, los despliegues, la seguridad, las pruebas y la recuperación. |
| [Revisión UX](REVISION-UX.md) | Traza la aplicación de los principios de Yablonski y Krug, los cambios realizados y la prueba pendiente con usuarios. |
| [Registro de cambios](../CHANGELOG.md) | Resume las modificaciones por versión. |
| [Conexión con Google Sheets](../google-apps-script/LEEME.md) | Contiene el procedimiento específico para configurar o actualizar el receptor. |

Estado documentado: **9 de septiembre de 2026**, aplicación e instrumento `2.2.0`, esquema `expert-validation/2.2`.
